Pet Salon Manager Pro - iPhone Web App package

このフォルダを HTTPS 対応のWebホスティングにアップロードすると、
SafariからURLを開いて使えるWebアプリになります。

iPhoneでアプリ化:
1. Safariで公開URLを開く
2. 共有ボタン
3. 「ホーム画面に追加」
4. 「追加」
5. ホーム画面のアイコンから起動

注意:
- この版はプロトタイプで、データは端末のブラウザ内に保存されます。
- 複数スタッフ・複数端末で共有するには、次の段階でクラウドDBと認証を追加します。
- HTTPSで公開する必要があります。
